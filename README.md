# Dukaan Jewelry Store

Premium Indian jewelry dropship store — Temple Choker, Evil-Eye Bracelet, Pearl Pendant.

Built with Next.js 14+, TypeScript, and Vanilla CSS. Dark-mode-first with gold and rose-gold accents.

## Getting Started

```bash
npm install
npm run dev
```
